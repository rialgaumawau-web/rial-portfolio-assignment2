# Rial Portfolio Website – Assignment 2 -

## Overview

This project is a personal portfolio website developed using Node.js, ExpressJS, EJS, and Bootstrap. The website contains four pages: Home, About Me, Projects, and Contact. The purpose of the project is to demonstrate the use of Express routing, EJS templates, Bootstrap styling, GitHub version control, and cloud deployment.

---

## Technologies Used

- Node.js
- ExpressJS
- EJS Templates
- Bootstrap 5
- GitHub
- Render

---

## Project Structure

The project was created using Express Generator with EJS support.

Main folders used in the project:

- routes
- views
- public

The routes folder contains the application routes.

The views folder contains all EJS pages:

- index.ejs
- about.ejs
- projects.ejs
- contact.ejs

The public folder stores assets such as images, CSS files, and media files.

---

## Website Features

### Home Page

The Home page introduces visitors to the portfolio website and provides navigation to the other sections.

### About Page

The About page contains personal information, a profile image, and an introduction video section.

### Projects Page

The Projects page displays projects using Bootstrap cards.

### Contact Page

The Contact page contains a contact form and personal contact information.

---

## Routing

The website uses ExpressJS routing to navigate between pages.

Routes implemented:

- /
- /about
- /projects
- /contact

Each route renders its corresponding EJS view using Express.

---

## Styling

Bootstrap was used to create the navigation bar, layout, forms, cards, and responsive design elements.

A custom stylesheet was also used to apply the portfolio color theme.
